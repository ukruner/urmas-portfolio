# Urmas Kruner Portfolio

A single page React portfolio for Urmas Kruner, built with Vite and hosted with GitHub Pages.

## Palette

The design uses a five-colour harmony rule:

- Deep ink: `#172121`
- Warm paper: `#f7f2e8`
- Sage: `#6f8f72`
- Amber: `#d99a3d`
- Coral: `#c75f4a`

## Commands

```bash
npm install
npm run dev
npm run build
npm run deploy
```

## Deployment

The Vite base path is configured for:

```text
https://ukruner.github.io/urmas-portfolio/
```

`npm run deploy` builds the app and publishes `dist` to the `gh-pages` branch.
